# 🚀 ORBIT-X | Interactive Space Exploration

**Explore the Universe, Discover the Unknown!**

## 🌌 1. Project Overview

ORBIT-X is an interactive space exploration web application developed as a final group project for the JavaScript course.

The application provides an engaging experience where users can explore the solar system, discover planets, learn about space missions, and interact with different space-related features.

The main purpose of this project is to demonstrate practical programming skills through an interactive, dynamic, and user-friendly web application.

## 🎯 2. Project Objectives

- Create an interactive and engaging web application.
- Apply JavaScript concepts learned throughout the course.
- Practice teamwork and collaborative development using Git and GitHub.
- Develop an organized and responsive user interface.
- Improve problem-solving and debugging skills.

## ✨ 3. Main Features

- **Home Page:** Introduction to the ORBIT-X universe.
- **Solar System:** Explore the solar system and its planets.
- **Planet Explorer:** Discover information about different planets.
- **Mission Control:** Explore space missions.
- **Launch Simulation:** Experience an interactive spacecraft launch simulation.
- **Spacecraft Information:** Learn about different spacecraft.
- **Interactive Quiz:** Test knowledge through space-related questions.
- **Dashboard:** View progress and saved activity records.
- **About Page:** Learn more about the project.

## 📁 7. Project Structure

The project is organized into separate folders to keep the code clean and maintainable.

- `public/` – Public assets.
- `src/` – Main application source code.
- `src/pages/` – Application pages.
- `src/scenes/` – Interactive scenes.
- `src/data/` – Project data.
- `src/systems/` – Application systems.
- `vibe_images/` – Project images and visual assets.
- `index.html` – Main HTML entry point.
- `package.json` – Project dependencies and scripts.

## ⚙️ 8. Installation and Setup

Follow these steps to run the project locally.

**Step 1: Clone the repository**

```bash
git clone https://github.com/pirzadamarjan-a11y/ORBIT-X-GROUP.git
```

**Step 2: Open the project folder**

```bash
cd ORBIT-X-GROUP
```

**Step 3: Install dependencies**

```bash
npm install
```

**Step 4: Start the development server**

```bash
npm run dev
```

**Step 5: Open the local URL**

Open the URL displayed in your terminal in a web browser.

## 💾 9. Data Storage

The application uses the browser's LocalStorage to save user-related information, including progress, mission records, and quiz results.

This data remains specific to the browser where it was saved.
